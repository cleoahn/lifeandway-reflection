나의 기록

클라우드 모드는 Supabase에 저장합니다. 로컬 모드는 이 기기에만 저장합니다. JSON 백업에는 개인 일기가 포함되므로 GitHub에 업로드하지 마세요.

기존 앱의 ‘전체 기록 백업’ 파일을 가져올 수 있습니다. 로그인한 계정과 개수를 확인한 후 업로드하며, 동일한 ID는 덮어쓰지 않습니다. 기존 앱과 백업 파일은 보존해 주세요.

클라우드 연결 설정

이 앱 전용 Supabase 프로젝트의 주소와 Publishable key만 입력하세요. 비밀 키는 입력하지 마세요. 노트북과 휴대폰에서 같은 값을 입력합니다.

연결 정보만 이 브라우저에 저장됩니다. 일기는 GitHub에 저장되지 않습니다.

나의 성찰 계정

계정 비밀번호는 Supabase Auth에서 처리합니다. 브라우저에 일기 캐시는 남기지 않습니다. 저장 전 내용은 페이지를 닫으면 사라질 수 있으니 TXT로 보관하세요.

다른 버전이 발견됐어요
